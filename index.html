Kebijakan Privasi Veyra AI

Terakhir diperbarui: 27 September 2026

Kebijakan ini berlaku untuk aplikasi Android Veyra AI (nama paket com.veyra.ai). Aplikasi ini gratis. Pengembangnya adalah pemilik akun GitHub KANZAPRO71. Veyra AI tidak menyediakan akun pengguna sendiri.

Data yang diproses

  • Mikrofon. Saat Anda menekan Mulai pada sesi langsung, aplikasi merekam suara dari mikrofon.
  • Teks percakapan. Ucapan yang dikenali dan balasan sesi dikirim sebagai bagian dari sesi langsung.
  • Kunci Gemini. Kunci API yang Anda simpan di Pengaturan disimpan di perangkat ini.
  • Preferensi di perangkat. Bahasa tampilan, bahasa percakapan, suara, kecepatan bicara, frasa tersimpan, dan riwayat yang ada di aplikasi disimpan di penyimpanan lokal perangkat.

Cara data digunakan

Suara dan teks dipakai hanya untuk menjalankan fitur yang Anda buka: terjemahan langsung di Live Talk, percakapan di Companion, atau jawaban singkat di Whisper. Kunci Gemini dipakai agar perangkat Anda dapat tersambung ke layanan Gemini. Preferensi dipakai agar pilihan Anda tetap ada saat aplikasi dibuka lagi.

Dengan siapa data dibagikan

Selama sesi langsung aktif, audio dan teks dikirim dari perangkat Anda ke Google Gemini API (generativelanguage.googleapis.com) memakai kunci API Anda. Pemrosesan itu tunduk pada Kebijakan Privasi Google dan ketentuan Gemini API.

Veyra AI tidak mengoperasikan server sendiri untuk aplikasi Android ini, tidak menjual data Anda, dan tidak membagikan data itu kepada pihak lain selain Google untuk sesi langsung tersebut.

Penyimpanan dan penghapusan

Kunci API, preferensi, frasa, dan riwayat tetap di perangkat. Data itu tidak diunggah ke server Veyra. Anda dapat menghapusnya dengan membersihkan data aplikasi di setelan Android, atau dengan menghapus aplikasi.

Izin perangkat

Aplikasi meminta internet agar sesi langsung dapat tersambung, dan mikrofon agar dapat mendengar ucapan Anda. Izin mikrofon hanya dipakai ketika Anda memulai sesi. Aplikasi juga memakai izin audio Android yang diperlukan untuk memutar balasan suara.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah 13 tahun, dan tidak dengan sengaja mengumpulkan data dari anak-anak.

Perubahan

Jika kebijakan ini berubah, tanggal di bagian atas halaman akan diperbarui. Versi publik halaman ini ada di https://kanzapro71.github.io/veyra-ai-privacy/.

Kontak

Pertanyaan privasi dapat dikirim lewat GitHub Issues pada repositori kebijakan ini.

English

Veyra AI (package com.veyra.ai) is a free Android app published by the owner of the GitHub account KANZAPRO71. The app has no Veyra user account.

When you start a live session, microphone audio and conversation text are sent from your device to the Google Gemini API using the Gemini API key you save in Settings. That key, along with language, voice, saved phrases, and on-device history, stays in local storage on your device. Veyra does not run its own server for this Android app, does not sell your data, and does not share it with anyone other than Google for that live session. Google's handling of the session is covered by Google's privacy policy and the Gemini API terms.

You can remove on-device data by clearing the app's storage or uninstalling it. The app is not directed at children under 13. Privacy questions: GitHub Issues.
